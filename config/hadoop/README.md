# Hadoop Cluster Configuration

This folder is mounted as `/opt/hadoop/etc/hadoop` on all containers
(NameNode, DataNodes, ResourceManager, NodeManager).

The `*.xml` and `*.xml.raw` files are automatically generated by the container
from the `.env` at the project root and persisted here.

## Environment Variables

The container converts `.env` variables into XML files:

```
CORE-SITE.XML_fs.defaultFS=hdfs://namenode:8020
        ↑           ↑
     file      property
```

## Bootstrap Scripts

The bootstrap scripts (`start-hdfs.sh`, `init-datanode.sh`) are located in
`scripts/` at the project root, mounted at `/scripts` in the containers.

## ⚠️ Warning

- `make clean` deletes the `dfs/name/` and `dfs/data/` directories from inside
  here (complete HDFS reset)
- Do not remove or rename this folder without adjusting `docker-compose.yml`
